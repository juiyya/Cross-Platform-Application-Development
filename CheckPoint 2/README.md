# lista de compras

aplicativo simples de lista de compras em react native. CheckPoint 2 

## como rodar

```bash
npm install
```

```bash
npx expo start
```

abra o aplicativo pelo **Expo Go** usando o QR Code ou pressione `w` para abrir no navegador.

## funcionalidades

- adicionar itens à lista
- visualizar os itens usando FlatList
- excluir itens da lista
- uso de useState para controlar a lista

## tecnologias

- React Native
- Expo
- JavaScript
